# Бой со слабым противником

**Где звучит.** Самые слабые враги: звери, мелкие хищники. У игры здесь своей музыки почти нет — сюда кладут, если хочется музыки и в таких стычках.

**Какие треки подходят.** Лёгкая перкуссия, короткие треки.

**Если здесь пусто**, играет папка `combat` («Бой — общая папка»).
