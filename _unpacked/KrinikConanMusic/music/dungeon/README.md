# Подземелья

**Где звучит.** Подземелья и пещеры: Клоака, подземелья у Наковальни королей-великанов, ледяная, каменная, песчаная и паучья пещеры, дворец Королевы-ведьмы, хранилища острова Сиптаха; пещеры модов Caverns of Set и Ymir's Respite.

**Какие треки подходят.** Тёмная, гнетущая музыка: дроны, низкие струнные, редкие удары.

**Если здесь пусто**, играет родная музыка игры.
