# Города и руины

**Где звучит.** Безымянный город и его окрестности, Сепермеру, обсерватория, Остров Телиф, Архивы, храм Сета, город нежити.

**Какие треки подходят.** Таинственная, древняя музыка: хоралы, арфа, медленные струнные.

**Если здесь пусто**, играет папка `explore` («Мир — общая папка»).
