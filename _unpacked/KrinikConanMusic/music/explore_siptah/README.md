# Остров Сиптах

**Где звучит.** Карта острова Сиптаха: побережье, пепельные земли, мёртвая зона, разливы, холмы, леса секвой, башня Сиптаха. Если вы играете только в Землях изгнанников, папка не понадобится.

**Какие треки подходят.** Морская, мистическая музыка.

**Если здесь пусто**, играет папка `explore` («Мир — общая папка»).
