# Реки и нагорья

**Где звучит.** Середина карты: речные долины, плодородные нагорья, плато каньона, горячие источники, пиратский берег и корабль.

**Какие треки подходят.** Светлая, просторная музыка: струнные, флейты, неторопливый оркестр.

**Если здесь пусто**, играет папка `explore` («Мир — общая папка»).
