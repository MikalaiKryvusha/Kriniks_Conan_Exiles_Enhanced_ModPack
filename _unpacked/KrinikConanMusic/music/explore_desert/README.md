# Пустыня

**Где звучит.** Юг карты: пески, оазисы, Гибельные курганы, Провал, стоянки пиратов и Псов пустыни; песчаные земли мода Caverns of Set.

**Какие треки подходят.** Сухие, тягучие, восточные мотивы: дудук, уд, барабаны, гортанное пение.

**Если здесь пусто**, играет папка `explore` («Мир — общая папка»).
