| `bash _config/bench-flight.sh <маршрут> <метка> [--video]` | замер: PresentMon (и видео экрана) ровно на время облёта |

Мод `_unpacked/KrinikConanBench` (прибор агента, вне манифеста): маршруты перечитываются на каждый `fly` — правка точек без перезапуска
игры; правка `main.lua` — только перезапуском. Скорость точки (5-е значение) — по земле: время участка = max(горизонталь, |перепад|) / скорость.
