<h3 align="center"><em>Krinik Mod Pack · лаунчер 1.1.1 / launcher 1.1.1</em></h3>

<a name="русский"></a>
## Русский · [English](#english)

Лаунчер 1.1.1 ускоряет повторное открытие таблички отзыва. Лаунчер прежних версий сам находит эту версию и показывает плашку «Вышел лаунчер 1.1.1». Нажмите на плашке кнопку «Обновить лаунчер». Когда лаунчер обновится, нажмите кнопку «Обновить сборку».

- Лаунчер 1.1.1 быстрее открывает табличку «Как прислать отзыв или отчёт о падении» при повторных нажатиях кнопки «Отзыв». На экране с масштабом 300 % повторное открытие таблички занимает около 0,03 секунды. Первое открытие после запуска лаунчера остаётся медленным, до 0,4 секунды. Это известная проблема.

Лаунчер 1.1.1 вышел вместе со сборкой [0.9.1-RC4](https://github.com/MikalaiKryvusha/Kriniks_Conan_Exiles_Enhanced_ModPack/releases/tag/v0.9.1-RC4). На странице выпуска 0.9.1-RC4 описаны изменения сборки и лежат её файлы.

<a name="english"></a>
## English · [Русский](#русский)

Launcher 1.1.1 speeds up repeated opens of the feedback panel. A launcher of an earlier version finds this version on its own and shows the notice “Launcher 1.1.1 is out”. Click “Update launcher” on the notice. When the launcher has updated, click “Update mod pack”.

- Launcher 1.1.1 opens the “How to send feedback or a crash report” panel faster when you click “Feedback” again. On a screen at 300 % scale a repeated open takes about 0.03 seconds. The first open after the launcher starts is still slow, up to 0.4 seconds. This is a known issue.

Launcher 1.1.1 was released together with mod pack [0.9.1-RC4](https://github.com/MikalaiKryvusha/Kriniks_Conan_Exiles_Enhanced_ModPack/releases/tag/v0.9.1-RC4). The 0.9.1-RC4 release page describes the mod pack’s changes and holds its files.
