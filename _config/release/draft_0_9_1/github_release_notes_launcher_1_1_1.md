<h3 align="center"><em>Krinik Mod Pack · лаунчер 1.1.1 / launcher 1.1.1</em></h3>

<a name="русский"></a>
## Русский · [English](#english)

Лаунчер 1.1.1 исправляет медленную табличку отзыва. Лаунчер прежних версий сам находит эту версию и показывает плашку «Вышел лаунчер 1.1.1». Нажмите на плашке кнопку «Обновить лаунчер». Когда лаунчер обновится, нажмите кнопку «Обновить сборку».

- Лаунчер 1.1.1 быстрее открывает табличку «Как прислать отзыв или отчёт о падении» по кнопке «Отзыв». Раньше при каждом следующем нажатии табличка открывалась примерно за 0,08 секунды. Теперь она открывается примерно за 0,01 секунды. В первый раз после запуска лаунчера табличка по-прежнему открывается примерно за 0,1 секунды.

Лаунчер 1.1.1 вышел вместе со сборкой [0.9.1-RC4](https://github.com/MikalaiKryvusha/Kriniks_Conan_Exiles_Enhanced_ModPack/releases/tag/v0.9.1-RC4). На странице выпуска 0.9.1-RC4 описаны изменения сборки и лежат её файлы.

<a name="english"></a>
## English · [Русский](#русский)

Launcher 1.1.1 fixes the slow feedback panel. A launcher of an earlier version finds this version on its own and shows the notice “Launcher 1.1.1 is out”. Click “Update launcher” on the notice. When the launcher has updated, click “Update mod pack”.

- Launcher 1.1.1 opens the “How to send feedback or a crash report” panel faster when you click “Feedback”. Each later click used to open it in about 0.08 seconds; it now opens in about 0.01 seconds. The first time after the launcher starts, the panel still opens in about 0.1 seconds.

Launcher 1.1.1 was released together with mod pack [0.9.1-RC4](https://github.com/MikalaiKryvusha/Kriniks_Conan_Exiles_Enhanced_ModPack/releases/tag/v0.9.1-RC4). The 0.9.1-RC4 release page describes the mod pack’s changes and holds its files.
