<h3 align="center"><em>Krinik Mod Pack 0.9.1-RC2 · Conan Exiles Enhanced 3.1.1</em></h3>

<a name="русский"></a>
## Русский · [English](#english)

RC2 исправляет ошибки, найденные в RC1. Полное описание версии 0.9.1, установка и известные проблемы приведены на странице выпуска [0.9.1-RC1](https://github.com/MikalaiKryvusha/Kriniks_Conan_Exiles_Enhanced_ModPack/releases/tag/v0.9.1-RC1).

- Исправлен баг карты в хабе. Метка вставала не туда, где вы щёлкнули, вторая метка не ставилась, а сброс не работал. Теперь карта работает.
- Исправлен баг кнопки начала приключения на вкладке «Путешествие». Кнопка не запускала путешествие, а вкладка показывала путешествия в устаревшем состоянии. Теперь кнопка запускает путешествие.
- Исправлен баг разговоров с NPC. Пока был открыт разговор, мир замирал, как в меню. Теперь мир идёт с обычной скоростью.
- Исправлен баг невидимых реплик NPC в разговорах. После выбора реплики NPC отвечал голосом, а текст ответа не появлялся. Теперь ответ виден.

<a name="english"></a>
## English · [Русский](#русский)

RC2 fixes the bugs found in RC1. The full description of 0.9.1, installation and known issues are on the [0.9.1-RC1](https://github.com/MikalaiKryvusha/Kriniks_Conan_Exiles_Enhanced_ModPack/releases/tag/v0.9.1-RC1) release page.

- Fixed a bug of the hub's map. A marker landed away from where you clicked, a second marker could not be placed, and the reset did nothing. The map works now.
- Fixed a bug of the button that starts an adventure on the Journeys tab. The button did not start the journey, and the tab showed journeys in an outdated state. The button starts the journey now.
- Fixed a bug of NPC conversations. While a conversation was open, the world froze as it does in a menu. The world keeps its normal pace now.
- Fixed a bug of invisible NPC lines in conversations. After you picked a reply, the NPC answered by voice, but the answer's text never appeared. The answer is visible now.
