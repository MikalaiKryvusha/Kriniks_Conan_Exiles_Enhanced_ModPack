# Съёмка кадров для страницы мода на Nexus

Приборы, которыми снимается и подписывается серия скриншотов `ConanCameraControl`.
Лежат здесь, а не в скретчпаде, по оплаченной причине: **предыдущий скрипт подписей
умер вместе с сессией**, и стиль, который владельцу понравился, пришлось потом
восстанавливать замером пикселей по уцелевшим кадрам.

## Порядок работы

```powershell
# 1. Владелец сам запускает игру и встаёт на точку — погода и место его выбор.
#    Серия снимается ОДНИМ заходом: игру между кадрами не закрывать.
.\shoot-series.ps1

# 2. Проверить машиной, что кадры действительно разные.
python series-check.py matrix <папка кадров>

# 3. Запечь подписи.
python caption.py <папка кадров> <папка подписанных>

# 4. Проверить, что плашка подписи ОДИНАКОВАЯ на всех кадрах.
python plate-check.py <папка кадров> <папка подписанных>

# 5. Собрать всё на один лист для вычитки владельцем.
python contact-sheet.py <папка подписанных> <лист.jpg>

# 6. Ванильный кадр — отдельно, он требует выключить мод и перезапустить игру.
.\shoot-vanilla.ps1
```

## Почему именно так

**Съёмка идёт через `agent-cmd.txt`, а не нажатием клавиш.** Замер 10.09.2026:
агент не может нажать ни одной клавиши мода — `Tab` до игры доходит, а `Numpad` и
`Ctrl+Numpad` до UE4SS нет: ни виртуальной клавишей, ни скан-кодом, ни при удержании
300 мс, при включённом NumLock и игре в фокусе. Серия «по клавишам» молча сняла бы
один и тот же кадр четырнадцать раз — именно так прошлый заход выдал три одинаковых
кадра под тремя разными подписями.

**Правило прицела зашито в `shoot-series.ps1` сторожем.** Слово владельца: «прицел
должен быть выше головы». Прицел — центр экрана, значит герой обязан быть НИЖЕ него:

```
герой ниже прицела, градусов = atan(offset_z / arm_length) − |camera_pitch|
```

Подъём камеры опускает героя в кадре, наклон поднимает обратно. Погасят друг друга —
герой окажется ровно на прицеле. На дистанции 950 подъём в 200 даёт всего 12°, и
наклон в 14° съедал его целиком: три дальних кадра ушли владельцу с прицелом на
голове героя. Теперь сценарий считает этот угол ДО съёмки и отказывается снимать
кадр, где он ниже порога.

**`series-check.py` — это машинный глаз.** Он не судит о красоте; он опровергает
ровно тот отказ, который случился: кадры, обязанные различаться, оказались
одинаковыми. Нужен потому, что возможность агента СМОТРЕТЬ на картинки в длинном чате
исчерпаема — API перестаёт их принимать, и дальше подписывать неувиденное нельзя.

**`style-probe.py` / `style-probe2.py` снимают стиль подписи с готового кадра** —
где стоит подложка, градиент это или заливка, какой высоты текст, какого цвета.
Тем и восстановлен стиль умершего скрипта.

**`plate-check.py` меряет плашку на готовых кадрах.** Ширину плашки первая
версия брала от длины САМОЙ подписи, а подписи разной длины — и на серии
плашка гуляла на 391 пиксель, десятую часть ширины кадра. Владелец увидел это
сам и назвал багом. Теперь плашка считается один раз на всю серию, по самой
длинной подписи, а сторож меряет её на готовых файлах и краснеет, если она
снова разъедется. Вердикт берётся по правому и горизонтальным краям: левый
край задан константой, но его ЗАМЕР гуляет на два десятка пикселей, потому что
мягкая кромка пересекает порог раньше на тёмном песке, чем на светлом.

**`variants.py` рисует несколько вариантов подписи на одном кадре.** Когда критерий
— вкус («стиль суперский»), спорить словами бесполезно и править вслепую тоже:
дешевле показать владельцу четыре варианта и услышать букву.

## Что НЕ версионируется

Сырые `.png` из съёмки (в родных 3840×2160 серия весит под полтораста мегабайт) —
см. `.gitignore`. В историю идут подписанные `.jpg`, которые и уедут на Nexus.
Пересъёмка стоит одного прогона, история — навсегда.
